# 社区专栏

> 面向所有 rocket-pi 爱好者的原创分享阵地，聚焦"我如何解决问题"与"我有哪些新玩法"。



### 1. 实战纪实
记录如何把 rocket-pi 用在真实项目中的全过程，例如、驱动适配、踩坑记录与最终效果。欢迎配合照片、原理图或视频链接。

### 2. 调试手记
聚焦定位与排障的思路，可以分享串口 log、示波器截图、定位步骤等。重点讲"发生了什么"、"为什么"以及"最后如何验证"。

### 3. 经验与成长
包括学习路线心得、面试/竞赛经验、效率工具、开源贡献心得等。更注重“软技巧”与可复用的方法。

## 投稿方式

1. 使用 Markdown 编写文章，建议直接在仓库 `docs/community/` 下新增文件
2. 在开头写明作者昵称、适用版本/环境、阅读前置
3. 通过 PR 提交；若不方便提 PR，可发送 md 或公开文档链接至 `2995560796@qq.com`
4. 通过审核后会在一周内合并并加上作者署名
