## 7.配置LED的电气属性

由于三个LED都是低电平点亮，一般 初始化的过程，我们会配置关闭LED，

- 分别点击 PA1,PB10,PB14，将GPIO output level 属性设置为high,配置后烧录程序默认会关闭LED
- 默认的GPIO mode 是推挽输出（推挽输出可以输出高电平，也可以输出低电平），此处我们不需要更改gpio的模式了,至此lLED的配置已经完成了

![image-20251112195807317](https://cloud.rocketpi.club/cloud/image-20251112195807317.png)

代码释意

```
void HAL_GPIO_EXTI_IRQHandler(uint16_t GPIO_Pin)
{
  /* EXTI line interrupt detected */
  if(__HAL_GPIO_EXTI_GET_IT(GPIO_Pin) != RESET)        // 1) 查：该引脚对应的 EXTI 挂起标志是否置位
  {
    __HAL_GPIO_EXTI_CLEAR_IT(GPIO_Pin);                // 2) 清：清除该 EXTI 挂起标志（写1清除）
    HAL_GPIO_EXTI_Callback(GPIO_Pin);                  // 3) 调：调用用户可重写的回调函数
  }
}
```

- 最终会调用到HAL_GPIO_EXTI_Callback(GPIO_Pin);   函数，我们一般把这样的函数叫做中断回调函数，查看该函数实现

![image-20251112200344930](https://cloud.rocketpi.club/cloud/image-20251112200344930.png)

代码释意

```
__weak void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  UNUSED(GPIO_Pin);   // 防止未使用形参导致编译告警
  /* NOTE: 不要改这里（HAL 源码）。
           需要回调时，请在用户文件里实现同名函数覆盖它。 */
}
```

要点：

1. `__weak`
   - “弱符号”。如果你的工程中**定义了同名的非弱函数**，链接时会**用你的实现**覆盖这里的空实现。
   - 这样 HAL 保留统一接口，你按需提供业务逻辑。
2. `UNUSED(GPIO_Pin)`
   - 只是消除“形参未使用”的告警；默认空实现里没有用到它。
3. **不要修改 HAL 源码**
   - 以后升级 HAL 容易被覆盖。正确做法是在用户代码（如 `stm32xxxx_it.c`、`main.c` 或你自己的 `.c`）里**写一个同名函数**。

将函数去掉__weak   ，放在文件stm32f4xx_it.c  

- 此处就是按键按下，留给我们需要编程的地方

**重点：中断要求快进快出，我们不会在中断里面加延时函数，一般会触发一个标志位，在main函数里面做处理**

![image-20251112201239347](https://cloud.rocketpi.club/cloud/image-20251112201239347.png)

填入此段代码

![image-20251112203438770](https://cloud.rocketpi.club/cloud/image-20251112203438770.png)

代码释意

```c
/* 在中断与主循环之间传递事件的标志位
 * volatile 防止编译器优化缓存，保证主循环能读到中断里最新写入的值
 */
volatile uint8_t key_flag = 0;

/**
 * @brief  外部中断回调（HAL 会在 HAL_GPIO_EXTI_IRQHandler() 中调用这里）
 * @param  GPIO_Pin 本次触发的 EXTI 引脚对应的“线”，例如 GPIO_PIN_0
 */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  /* 只处理我们关心的按键那一条 EXTI 线（例如 PA0） */
  if (GPIO_Pin == KEY_PA0_Pin)
  {
    /* 记录“上一次被判定为有效按键事件”的时间戳（ms）
     * static 保留上次值；放在这里即可，不必全局
     */
    static uint32_t last_press_tick = 0;

    /* 当前毫秒节拍（由 SysTick 提供，默认 1ms 递增） */
    uint32_t now = HAL_GetTick();

    /* 20ms 软件去抖：
     * 使用无符号减法比较 (now - last_press_tick) >= 20
     * 即使 HAL_GetTick() 发生 32 位溢出也能正确比较
     */
    if ((now - last_press_tick) >= 20U)
    {
      /* 更新最近一次“有效事件”时间点 */
      last_press_tick = now;

      /* 置位事件标志，让主循环读取后处理（并清零） */
      key_flag = 1;
    }
  }
}

```

主循环读取示例

![image-20251112203746731](https://cloud.rocketpi.club/cloud/image-20251112203746731.png)

```
    extern volatile uint8_t key_flag; 
    
    
    if (key_flag)
    {
      key_flag = 0;
      HAL_GPIO_TogglePin(LED_R_GPIO_Port, LED_R_Pin);
      HAL_GPIO_TogglePin(GPIOB, LED_G_Pin | LED_B_Pin);
    }  
```

声明一个在别处定义的全局变量（通常在中断回调里置位）。

`volatile` 确保主循环每次都从内存读取最新值（因为中断可能随时修改它）。

轮询事件：如果 `key_flag` 被中断置位（=1），就进入处理分支。

清零标志：`key_flag = 0;` 表示“这次事件已处理”，防止重复触发。
