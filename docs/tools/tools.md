- edg /chrome 浏览器网页翻译 （优点：英文网页直接变中文，可自行探索~）

- VScode也可以在插件商店直接搜typora

### 流程图绘制

- processon <a href="https://www.processon.com/" target="_blank">Link</a>  

*ProcessOn*是一款专业在线作图工具和知识分享社区，支持AI一键生成思维导图和流程图。可绘制甘特图、ER图、UML、网络拓扑图、电路图、平面图、鱼骨图、组织结构图等~
