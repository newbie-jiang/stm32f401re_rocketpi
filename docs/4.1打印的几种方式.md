## 功能：使用几种不同的方式打印输出



## 1.进入mcu选择器界面

- 打开STM32cubeMX，点击ACCESS TO MCU SELECTOR

![image-20251106011342611](https://cloud.rocketpi.club/cloud/image-20251106011342611.png)

## 2.选择芯片型号

- 步骤1：在Commercial Part Number 输入  F401RE
- 步骤2：选择STM32F401RET6 （其他芯片可自行选择）
- 步骤3：点击Start Project

![image-20251106011635971](https://cloud.rocketpi.club/cloud/image-20251106011635971.png)

## 3.晶体振荡器选择

- 步骤1：点击System Core
- 步骤2：点击RCC
- 步骤3：High Speed Clock(HSE) 选择 Crystal/Ceramic Resonator 

![image-20251106012005990](https://cloud.rocketpi.club/cloud/image-20251106012005990.png)

## 4.时钟配置

- 步骤1：点击Clock Configuration  
- 步骤2：input frequency输入8  (因为 rocketpi 硬件设计使用外部晶振为8Mhz，所以此处输入8)
- 步骤3：选择HSE
- 步骤4：在HCLK的输入框中输入84，接着回车，回车之后可能会弹出一个确认框，点击OK,会自动配置时钟，等待配置完毕

![image-20251106013613146](https://cloud.rocketpi.club/cloud/image-20251106013613146.png)

## 5.配置调试接口

- 步骤1：点击SYS
- 步骤2：Debug选择栏  选择Serial Wire

![image-20251106014323818](https://cloud.rocketpi.club/cloud/image-20251106014323818.png)

## 6.配置UART

PA2是usart调试的发送脚，PA3是usart调试的接收脚

- 点击PA2 设置为USART2_TX
- 点击PA3设置为USART_RX

![image-20251113000631226](https://cloud.rocketpi.club/cloud/image-20251113000631226.png)

开启usart的异步模式

步骤1：点击USART2

步骤2：将USART2的模式配置为 异步（Asynchronous）

![image-20251113001143406](https://cloud.rocketpi.club/cloud/image-20251113001143406.png)

## 7.生成代码

- 步骤1：点击Project Manager
- 步骤2：填写此次要创建的工程名字，（注意这里一定不要使用中文名）
- 步骤3：这个工程保存的路径（注意这里一定不要有中文路径，否则生成的工程会有问题）
- 步骤4：生成的工程选择 MDK-ARM  版本为v5.27（版本可以根据自己安装keil版本选择，一般来说高版本的keil可以向下兼容）

![image-20251106021327300](https://cloud.rocketpi.club/cloud/image-20251106021327300.png)

- 点击Code Generator
- 软件包选择 copy only the necessary files (仅复制使用到的库文件)
- 生成的文件选择  Generate peripheral initialization as a pair .c/.h files perpheral

![image-20251106022353098](https://cloud.rocketpi.club/cloud/image-20251106022353098.png)

最后，点击GENERATE CODE 即可生成代码

![image-20251106022513985](https://cloud.rocketpi.club/cloud/image-20251106022513985.png)

代码释意

```
#ifdef __GNUC__  // 使用 GCC/ARM-GCC（如 arm-none-eabi-gcc）时的重定向
// 说明：newlib 里 printf/scanf 最终会调用 _write/_read，
// 我们在这里把它们重定向到 UART2，达成 printf→串口、scanf←串口 的效果。

int _write(int file, char *ptr, int len) {
    // 将 ptr 指向的 len 字节数据经 UART2 发送
    // HAL_MAX_DELAY：阻塞等待直到发送完成（注意：在中断上下文中不安全）
    HAL_UART_Transmit(&huart2, (uint8_t*)ptr, len, HAL_MAX_DELAY);
    return len;  // 返回已写入字节数，printf 认为写入成功
}

int _read(int file, char *ptr, int len) {
    // 从 UART2 接收 len 字节到 ptr
    // 同样是阻塞式，直到收到足够字节才返回
    HAL_UART_Receive(&huart2, (uint8_t*)ptr, len, HAL_MAX_DELAY);
    return len;  // 返回已读取字节数，scanf 认为读取成功
}

#elif defined(__ARMCC_VERSION)  // 使用 Keil Arm Compiler（ArmCC/ArmClang）

// 说明：在 ArmCC/ArmClang 下，标准库的 putchar/getchar 默认走 fputc/fgetc。
// 重写它们即可将 printf/scanf 重定向到 UART2。

int fputc(int ch, FILE *f) {
    // 发送单个字符 ch 到 UART2
    uint8_t c = (uint8_t)ch;
    HAL_UART_Transmit(&huart2, &c, 1, HAL_MAX_DELAY);
    return ch;  // 返回发送的字符，表示成功
}

int fgetc(FILE *f) {
    // 从 UART2 阻塞读取一个字节
    uint8_t ch;
    HAL_UART_Receive(&huart2, &ch, 1, HAL_MAX_DELAY);
    return (int)ch;  // 返回读取到的字符
}

#else
    #error "Unsupported compiler"  // 既不是 GCC 也不是 ArmCC，则在编译期报错
#endif

```

### 第二种不使用微库

按照步骤 取消勾选 Use Micro LIB

![image-20251113003323787](https://cloud.rocketpi.club/cloud/image-20251113003323787.png)

在usart.c文件中再添加如下代码

![image-20251113003604813](https://cloud.rocketpi.club/cloud/image-20251113003604813.png)

```c
#ifndef __MICROLIB        // 如果没有使用 MicroLIB（Keil 的轻量级 C 库），则执行以下代码

#pragma import(__use_no_semihosting)   // 告诉编译器：不使用半主机模式（Semihosting）

// 定义一个 FILE 结构体，占位用，防止标准库中引用 FILE 出错
struct __FILE
{
    int a;   // 占位成员，没有实际意义
};

// 定义标准输入输出对象（标准库函数如 printf/scanf 会用到）
FILE __stdout;   // 标准输出（如 printf）
FILE __stdin;    // 标准输入（如 scanf）

// 定义系统退出函数（防止链接器报 _sys_exit 未定义的错误）
// 半主机模式中该函数用于程序结束时与调试器通信
// 在裸机环境下无需此功能，所以留空即可
void _sys_exit(int x)
{
    // 空实现，避免半主机调用导致程序卡死
}

#endif   // 结束 #ifndef __MICROLIB 判断

```

### 第三种，使用自定义的函数

```c
/* ========= 配置区域 ========= */
#ifndef UART_LOG_INSTANCE
#define UART_LOG_INSTANCE  huart2      // 改成你要使用的 UART 句柄
#endif

#ifndef UART_LOG_TIMEOUT
#define UART_LOG_TIMEOUT   1000        // 发送超时(ms)
#endif

#ifndef UART_LOG_BUF_SIZE
#define UART_LOG_BUF_SIZE  256         // 格式化缓冲区大小（按需调整）
#endif
/* ========================== */

static inline void uart_write_blocking(const uint8_t *data, size_t len)
{
    /* 阻塞式发送：不在中断上下文中调用 */
    HAL_UART_Transmit(&UART_LOG_INSTANCE, (uint8_t*)data, (uint16_t)len, UART_LOG_TIMEOUT);
}

/* 把 \n 规范为 \r\n 并发送（避免终端只换行不回车的问题） */
static void uart_write_with_crlf(const char *s, size_t len)
{
    for (size_t i = 0; i < len; ++i) {
        char c = s[i];
        if (c == '\n') {
            const char crlf[2] = {'\r','\n'};
            uart_write_blocking((const uint8_t*)crlf, 2);
        } else {
            uart_write_blocking((const uint8_t*)&c, 1);
        }
    }
}

/* 1) 直接输出字符串（自动 CRLF 规范化） */
void uart_puts(const char *s)
{
    if (!s) return;
    uart_write_with_crlf(s, strlen(s));
}

/* 2) printf 风格输出（可安全输出二进制中的 '\0' 之前的内容） */
int uart_printf(const char *fmt, ...)
{
    char buf[UART_LOG_BUF_SIZE];
    va_list ap;
    va_start(ap, fmt);
    int n = vsnprintf(buf, sizeof(buf), fmt, ap);
    va_end(ap);

    if (n < 0) return n;  // 格式化失败

    /* 若被截断，n >= sizeof(buf)，分段发送避免丢字 */
    size_t out_len = (n < (int)sizeof(buf)) ? (size_t)n : (size_t)sizeof(buf) - 1;
    uart_write_with_crlf(buf, out_len);

    /* 如果被截断，可追加提示（可选）
    if (n >= (int)sizeof(buf)) {
        uart_puts("...[truncated]\n");
    }
    */
    return n;
}

/* 3) 十六进制打印（可选，调试时很好用） */
void uart_hexdump(const void *data, size_t len, const char *title)
{
    const uint8_t *p = (const uint8_t*)data;
    if (title) uart_printf("%s (len=%u):\n", title, (unsigned)len);

    char line[80];
    for (size_t i = 0; i < len; i += 16) {
        int pos = 0;
        pos += snprintf(line + pos, sizeof(line) - pos, "%08X  ", (unsigned)i);

        /* hex */
        for (size_t j = 0; j < 16; ++j) {
            if (i + j < len) pos += snprintf(line + pos, sizeof(line) - pos, "%02X ", p[i + j]);
            else              pos += snprintf(line + pos, sizeof(line) - pos, "   ");
            if (j == 7) pos += snprintf(line + pos, sizeof(line) - pos, " ");
        }

        /* ascii */
        pos += snprintf(line + pos, sizeof(line) - pos, " |");
        for (size_t j = 0; j < 16 && i + j < len; ++j) {
            uint8_t c = p[i + j];
            pos += snprintf(line + pos, sizeof(line) - pos, "%c", (c >= 32 && c <= 126) ? c : '.');
        }
        pos += snprintf(line + pos, sizeof(line) - pos, "|\n");

        uart_puts(line);
    }
}
```
