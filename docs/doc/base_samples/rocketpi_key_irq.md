## 功能说明

- 中断消除按键抖动（非阻塞），实现按键翻转LED

## 硬件连接

- PA0  高电平触发
- LED  PA1    PB10    PB14    低电平点亮

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
  if (GPIO_Pin == KEY_PA0_Pin)
  {
    static uint32_t last_press_tick = 0;
    uint32_t now = HAL_GetTick();

    if ((now - last_press_tick) >= 20U)
    {
      last_press_tick = now;
      key_flag = 1;
    }
  }
}
