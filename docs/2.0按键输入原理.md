## 按键的原理

按键本质上就是一个通断器，按键可以简单分为两类：带自锁 和 不带自锁

- 带自锁的按键常用的  比如保护闸  家里的灯的开关，按一下电源接通了，再按一下电源断开了，常用于电源开关控制
- 不带自锁的按键，通常用于 **短时间控制** 或 **临时性操作**，比如鼠标键盘，以及开发板上的一些控制按键，当按下时电路接通，松开时电路断开，比如主包在打CSGO,要操作人物射击，要不断鼠标左键，就是按下才触发，松开就不触发了

## 不带自锁的按键，原理图上表现为

- SW1在没有按下时，此时PA0 检测出来的是高电平，当按键按下时，这时候PA0检测出来就是低电平
- 电容在此处的作用是消抖

![image-20251111001007660](https://cloud.rocketpi.club/cloud/image-20251111001007660.png)

### 解释：

按键在被按下或松开时，往往会出现“抖动”现象，即按键触点短时间内会多次接触和断开，导致电路状态的不稳定。这种现象会使得微控制器接收到多个按键触发信号，导致误操作。

### 电容的作用：

- **去抖动**：C14通过与R16一起构成RC滤波电路，帮助平滑按键的触发信号，消除由按键抖动引起的误触发。电容C14可以通过存储电荷，平滑按键的电平变化，确保只有稳定的信号被传递到后续电路或微控制器（PA0引脚）。

这样，按键的输入信号就会被有效地去抖动，从而避免因为按键触点的抖动而产生多次信号变化。
