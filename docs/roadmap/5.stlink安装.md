`dpinst_amd64.exe` 和 `dpinst_x86.exe` 是 **ST-Link** 驱动程序的安装文件，它们分别针对不同的系统架构：

- **`dpinst_amd64.exe`**：适用于 **64位** 系统（AMD 或 Intel 处理器）。
- **`dpinst_x86.exe`**：适用于 **32位** 系统（AMD 或 Intel 处理器）。

**双击 dpinst_amd64.exe安装  stlink驱动**
