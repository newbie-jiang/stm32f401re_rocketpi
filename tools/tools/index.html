    工欲善其事，必先利其器¶

    以下工具专为Rocket-Pi打造 (请勿滥用)

    • ♨在线串口工具使用 Rocket Pi serial tools 任意开发板串口通信都可~

    • 🛩RocketPi遥杆打飞机游戏 Rocket Pi  plan game Rocketpi程序支持， github gitee

    • 🍭图片取模工具(支持批量) Rocket Pi  image tools Rocketpi程序支持， github gitee

    • 🧙ymodem串口升级 Rocket Pi  ymodem tools Rocketpi程序支持， github gitee

    • 🛜180°超声波雷达检测 Rocket Pi  radar tools Rocketpi程序支持， github gitee

    • 📷简易录像 easy video 支持浏览器以及ios设备直接录像，安卓未测试

    • 🐳keil map文件分析工具keil map 可快速对文件flash，ram占用排名
    • 🏘️物联网智能家居控制台 Rocket Pi smart home Rocketpi程序支持， github gitee
    • 🌏物联网FOTA升级控制台 Rocket Pi fota Rocketpi程序支持， github gitee
    • 🔊文本/音频 转PCM Rocket Pi audio to pcm Rocketpi程序支持， github gitee

    流程图绘制¶

    • processon Link

    ProcessOn是一款专业在线作图工具和知识分享社区，支持AI一键生成思维导图和流程图。可绘制甘特图、ER图、UML、网络拓扑图、电路图、平面图、鱼骨图、组织结构图等~
