## 功能描述

示例通过设备树别名 `motorina/motorinb` 获取 TIM4_CH1/CH2 两路 20 kHz PWM 通道，以满足 L9110H 的推挽输入要求。`motor_profile()` 会先关闭另一侧 PWM，随后调用 `ramp_channel()` 以 5% 步进、每 120 ms 更新一次占空比，从 0→100%、保持 1.2 s、再降回 0%，从而实现无突变的加减速；两个方向轮流执行，期间 `motor_stop()` 始终把两路同时拉低，避免刹车时短路。

该流程示范了如何用 `pwm_set_dt()` 在 Rocket Pi 上控制 L9110H：将占空比映射为电机电压，实现自动正转/反转循环，并通过 `pwm_is_ready_dt()` 与错误打印观察到 PWM 控制是否成功。

## 编译

```
west build -p always -b rocket_pi l9110h
```

20 kHz 驱动  程序循环执行“正转→停→反转→停”的速度曲线：在某个方向时先把另一路 PWM 关死，再以 5% 步进、每步 120 ms 的方式从 0% 占空比爬升到 100%，保持 1.2 s，随后同样方式降到 0%，最后双路都关断并等待 0.8 s 后换方向。
