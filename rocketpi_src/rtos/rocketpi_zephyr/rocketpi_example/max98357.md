## 功能描述

示例通过设备树别名 `i2s_tx` 绑定 I2S2，并可选控制 `amp_sd` GPIO 上电，使 MAX98357A D 类功放进入播放状态。`audio_i2s_start()` 配置 16 bit、单声道、`I2S_FMT_DATA_FORMAT_I2S`、采样率取自 `audio.h`，然后用 `K_MEM_SLAB_DEFINE` 预先分配 4 个 256 frame 的缓冲区，将 `audio_track[]` 的 PCM 数据填充到 block 中，通过 `i2s_write()` + `I2S_TRIGGER_START/DRAIN` 流式推送，最后清空 TX 队列。

得益于内存池的循环复用，CPU 只需 memcpy PCM 并排队即可完成整首音频的播放；示例也展示了如何在 Rocket Pi 上驱动 MAX98357 的必要步骤（上电、配置 I2S 时钟、补 0 避免 underrun），方便扩展到更复杂的音频应用。

## 编译

```
west build -p always -b rocket_pi max98357
```
