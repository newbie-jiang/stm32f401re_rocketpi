## 功能描述

本示例在 PB1（TIM1_CH3N）上用 STM32F4 的 PWM+DMA 驱动 30 颗 WS2812B，`ws2812_ll_init()` 直接通过 LL API 配置 GPIO、TIM1 以及 DMA2_Stream5，并根据系统时钟计算 0.35 µs / 0.7 µs 的 CCR 值，同时为灯带末尾插入 >50 µs 的复位槽。`ws2812_encode()` 会把 `driver_ws2812b.c` 里的 GRB 帧缓冲逐 bit 转成 PWM 脉宽，再由 DMA 自动更新 CCR；DMA 中断通过信号量通知主线程，确保完整帧传输后才能开始下一次刷新。

应用层轮流调用 `ws2812b_test_blink/chase/rainbow/breathe/theater_chase/gradient_wipe` 等函数生成闪烁、追逐、彩虹、呼吸、剧院追逐、渐变擦除等效果，并在每个模式之间清屏，展示了 `ws2812b_fill()` 与 `ws2812b_show()` 的典型用法。整个流程证明：即使该引脚不支持 SPI，只要利用 TIM1+DMA 也能满足 WS2812B 对时序的苛刻要求。

## 编译

```
west build -p always -b rocket_pi ws2812b
```
