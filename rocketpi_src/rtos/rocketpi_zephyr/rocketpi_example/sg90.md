## 功能描述

示例通过别名 `servo0` 取得 50 Hz PWM 输出，再将 0~180° 线性映射为 0.5 ms~2.5 ms 脉宽（确保限制在 SG90 的可控区间），最后在主循环里以 1° 步进、5 ms 间隔往返扫动。`angle_to_pulse_us()` 使用整数算法避免浮点，同时在起始进入 90° 中位，防止上电时舵机猛冲。

程序展示了 Rocket Pi 上配置 `pwm_set_dt()` 拉高/拉低占空比、以打印日志观察角度的完整过程，可直接复用到其他模拟舵机，只需调整别名和脉宽范围即可。
## 编译

```
west build -p always -b rocket_pi sg90
```
