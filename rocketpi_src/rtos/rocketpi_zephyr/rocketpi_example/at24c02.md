## 功能描述

示例通过 `zephyr,i2c-bitbang` 软 I²C（PC14/PC15）驱动一颗 AT24C02 EEPROM，并调用移植自开源库的 `driver_at24cxx_read_test()` 逐段写入/读取校验。初始化阶段会用 `DRIVER_AT24CXX_LINK_*` 把 GPIO、延时、日志等钩子绑定到 Zephyr，随后循环在 0x0000~0x00E0（步长 0x20）写入固定序列、立刻读回并比对，过程中会打印器件信息、电压范围、驱动版本以及每段测试通过与否。

借由该例程可以验证 Rocket Pi 上软 I²C 的时序、电平配置与 EEPROM 供电是否正确，同时也提供了 AT24 系列常用 API（init/read/write/deinit）的调用方式，方便后续扩展成实际的数据存储功能。



## 编译

```
west build -p always -b rocket_pi at24c02
```
